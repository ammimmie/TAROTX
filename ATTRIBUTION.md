# External assets / attribution notes

TAROTX references Rider–Waite–Smith tarot card image URLs hosted by Wikimedia Commons. The public build does not bundle those card image files; the browser requests them from Wikimedia when a selected card is revealed.

Typography is requested from Google Fonts by the existing page stylesheet. No font files are included in this package.

The application includes fallback card artwork so a reading can still complete if a remote card image is unavailable.
